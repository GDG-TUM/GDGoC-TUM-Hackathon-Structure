    Participation guidelines

    Repository map

    Every file links straight to GitHub.

    How to contribute

    1. Fork or clone the repository.
    2. Create a branch for your changes.
    3. Add resources or improve docs in the right folder.
    4. Use descriptive file names with a short description, source link and level.
    5. Open a pull request, or follow the process agreed by organisers.

    Link to official sources rather than uploading copyrighted course material.
