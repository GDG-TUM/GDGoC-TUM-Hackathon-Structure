# Learning Resources

This folder is the central place for materials shared with GDG on Campus TUM members during the Hackathons & Solutions Challenge programme.

## How resources will be organised

Organisers can add files or create subfolders as the programme develops. Suggested categories:

```text
resources/
├── README.md
├── hackathon-foundations/
├── ideation-and-sdgs/
├── team-project-planning/
├── web-development/
├── cloud-computing/
├── mobile-development/
├── ai-machine-learning/
├── cybersecurity/
├── google-developer-tools/
├── prototyping-and-testing/
└── pitching-and-entrepreneurship/
```

Create only the folders you need. Empty folders are not tracked by Git unless they contain a file, so add a short `README.md` or `.gitkeep` if needed.

## Adding a resource

For each resource, include:
- **Title**
- **Topic/track**
- **Format:** PDF, slides, video, link, code, worksheet, etc.
- **Level:** Beginner, intermediate or advanced
- **Short description:** what members will learn
- **Source and licence:** especially for third-party content
- **Last checked:** when the link was last confirmed to work
